# wod
ウディタで変な処理を作るときに使えるC式プログラミング言語

かなりバグだらけなので自己責任でお願いします。

字句解析と構文解析に関してはjlox(https://github.com/munificent/craftinginterpreters)に基づいて作りました。

## 割と重大なバグなど
- 現在、ASCIIしか扱えない
- リテラルをinline関数に渡した場合、関数内で該当する引数に値を格納できない（コンパイラー側でエラーが出る）
- `continue`文はforループ内で正しく機能しない（更新文は実行されない）
- `use-globals`でコンパイルする場合、`main`以外の関数がすべてinlineでないと出力したプログラムが正しく機能しないことはある
- `use-globals`でコンパイルする場合、f文字列内では文字列変数が正しく扱われない

## 使い方
```
.\wodc.exe <入力ファイル> <出力ディレクトリ> [use-globals]
```
`use-globals`は何の値でも`true`と同等です（オフにする場合は何も入れない）。`use-globals`でコンパイルする場合、CSelf変数の代わりに通常変数(v[])と文字列変数(s[])を使います。CSelfで足りない場合は役に立ちますが、上記の通りいろいろバグがあります。
